# Отбор случаев из таблицы

Источник: «База документов и обязательных действий РФ — сроки и оформление.xlsx», 153 строки. Каталог включает 40 случаев из таблицы, пять специализированных сценариев и произвольное событие.

В таблице встречаются общие ссылки сразу для группы разных услуг. Поэтому они не считаются индивидуально проверенными правилами. Для новых случаев приложение хранит подтверждённую пользователем дату, показывает подготовку, следующие действия и ссылку на профильное ведомство. Оно не назначает обследования и не вычисляет универсальные юридические сроки по приблизительным данным.

Обозначения: **Специализированный** — исходный сценарий паспорта, загранпаспорта, ОСАГО, налогов или обследования; **По дате** — отдельный шаблон с подтверждённым сроком; **Своё событие** — ручная запись для индивидуальных условий. Коды RF обозначают строки исходной таблицы; ID приложения и правила редактируются в [shared/content.ts](../shared/content.ts).
