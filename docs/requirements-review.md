## Что остаётся перед сдачей

1. Указать фактический ник бота в `MAX_BOT_USERNAME` и подтвердить ссылку. Отображаемое имя не заменяет ник.
2. Обеспечить непрерывный HTTPS-сервер, выполнить `npm run bot:subscribe` (webhook и меню команд), затем `npm run bot:check`.
3. Пройти сценарий `verification.md` в мобильном и веб-клиентах MAX. Подтвердить отдельно ответ `/test` и плановое уведомление при закрытом календаре.
4. Заполнить команду и служебные поля презентации. Рабочие секреты передать в закрытых материалах организаторам, не коммитить. Указать commit hash из финального репозитория.
5. Провести интервью и пилот либо честно оставить гипотезы. Подготовить законные основания обработки данных и эксплуатационные документы перед пилотом с реальными данными.

Полное соответствие условиям допуска нельзя подтвердить без работающего MAX-сценария и заполненных материалов сдачи. Локальная сборка и тесты закрывают техническую часть, доступную для проверки в этой среде.
