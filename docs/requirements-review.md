## Техническая проверка

28.09.2026: сборка Linux/amd64 завершена примерно за 65 секунд без первой загрузки базового образа; 27 серверных тестов и 7 браузерных сценариев пройдены. Проверены запуск отдельного Docker-демо, сохранение события после перезапуска и конфигурация Caddy. MAX API подтвердил бота и webhook; публичный HTTPS ответил на проверку здоровья. Проверка ARM64 не завершена.

Проверки включают валидацию дат, подпись MAX, изоляцию пользователей, очередь и повторы, кнопки бота, совместимость старых ID, каталог, импорт PDF/OCR и сохранение событий. Команды доступны в [development.md](development.md#проверки).

Docker использует Linux-образы Node.js 22 и Caddy. Windows и macOS требуют Docker Desktop, Linux — Docker Engine или Desktop. Нативная зависимость SQLite собирается внутри Linux-образа; компилятор и зависимости разработки исключаются из рабочего образа. Это устраняет зависимость от установленного на хосте Node.js и инструментов сборки. Проверка на одном хосте не доказывает работу на всех ОС и архитектурах.

## Что нужно завершить перед сдачей

1. Пройти основной путь в реальных мобильном и веб-клиентах MAX, получить плановое уведомление при закрытом календаре и сохранить результат проверки.
2. Обеспечить доступность сервера на всём периоде оценки и подготовить рабочий доступ проверяющему через MAX.
3. Передать закрытый первый слайд с параметрами окружения; сверить схему `DATA-API.yaml` с организаторами.
4. Передать финальный commit hash либо архив исходников с SHA-256, затем зафиксировать версию до конца соответствующего этапа.
5. Перед пилотом с реальными персональными данными подготовить основания обработки, сроки хранения, эксплуатационные документы и резервное копирование.

Полное соответствие всем условиям сдачи пока не подтверждено: оставшиеся пункты нельзя заменить локальной сборкой или автоматическими тестами.
